An Emacs package for browsing and managing Linear.app issues with a Magit-style UI. Pure Emacs Lisp, no external dependencies.

Collapsible tree view organized by teams, projects, and workflow states. Change status, priority, labels, and assignee via transient menus. Create issues, copy branch names, and open in browser — all without leaving Emacs.
